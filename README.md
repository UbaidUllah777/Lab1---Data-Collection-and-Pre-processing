# Data Engineering Lab 1

This project demonstrates an end-to-end data engineering workflow using a synthetic Ontario retail sales dataset. The notebook covers data loading, data structures, profiling, quality checks, cleaning, transformation, feature engineering, aggregation, serialization, and data dictionary creation.

## Environment Setup

From the project root, create and activate the virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the pinned project dependencies:

```powershell
python -m pip install -r requirements.txt
```

To open the notebook, start Jupyter:

```powershell
jupyter notebook
```

Then open `notebooks/DataEngineering_Lab1.ipynb` in Jupyter or VS Code.

## Requirements

`requirements.txt` contains the pinned Python packages required by the project, including pandas, NumPy, Jupyter, Matplotlib, Seaborn, and notebook support dependencies. Installing from this file helps reproduce the project environment consistently.

## Source Module

`src/Load_data.py` provides the `LoadSales` class, which loads the sales CSV, cleans text and numeric fields, removes invalid or duplicate records, fills missing sales amounts when possible, and calculates total sales.

Processed CSV and JSON files generated by the notebook are saved in the `output/` directory.
